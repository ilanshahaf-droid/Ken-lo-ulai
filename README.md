# כן · לא · אולי – PWA (מבנה שטוח, בלי תיקיות)

## למה שינינו את המבנה
בניוסיטיז הגרירה לא יצרה תיקיות `icons/` ו-`screenshots/` בפועל, וכל הקבצים עלו ישר ל-Home. אז עדכנו את הקוד כך שהוא מצפה לכל הקבצים **בשורש האתר, בלי תיקיות בכלל** — בדיוק כמו שכבר קיים אצלכם.

## מה יש בזיפ
```
index.html
manifest.json
sw.js
icon-192.png
icon-512.png
icon-maskable-512.png
welcome.png
play.png
README.md
```

## מה לעשות בניוסיטיז
1. היכנסו ל-Edit Site → Home
2. **מחקו** (Delete) את `manifest.json` ו-`sw.js` הישנים
3. **Upload** את `manifest.json` ו-`sw.js` החדשים מהזיפ הזה (הם מצביעים לקבצים בלי `icons/` או `screenshots/` בנתיב)
4. `index.html` צריך גם הוא להתעדכן — מחקו אותו והעלו את הגרסה החדשה מהזיפ (הקישורים בו תוקנו גם כן)
5. שאר הקבצים (`icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `welcome.png`, `play.png`) כבר קיימים אצלכם בשמות הנכונים בשורש — אין צורך לגעת בהם

## בדיקה
פתחו את https://ilanayelet.neocities.org/manifest.json ווודאו שהנתיבים בפנים הם `/icon-192.png` וכו' (בלי `icons/`). אחר כך רעננו את PWABuilder ובדקו שה-Action Items נעלמו.

## עדכון בעתיד
כל הקבצים באותה תיקייה, אז זה פשוט: עורכים ומעלים מחדש. אם משנים את `index.html` באופן משמעותי, כדאי לעדכן את `CACHE_NAME` בתוך `sw.js` (למשל מ-`v3` ל-`v4`) כדי שהטלפונים יקבלו את הגרסה החדשה ולא את הישנה מהמטמון.
